# Creaciones Yazmin — diseño definitivo

Esta versión recrea la composición de la imagen aprobada: encabezado, botones, buscador,
carrusel, Recientes, tarjetas de producto y Crea tu moño.

## Archivos
- index.html
- style.css
- script.js
- assets/

## Publicar en GitHub Pages
Sube todos los archivos conservando la carpeta `assets`. Luego activa Pages desde
Settings → Pages → Deploy from branch → main → / (root).

Las funciones de login, registro, pedidos, contacto y personalización están preparadas
visualmente y se conectarán a Firebase/WhatsApp/pagos en la siguiente integración.
